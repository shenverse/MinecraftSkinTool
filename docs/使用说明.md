# 使用说明

## 第一步：打开工具

双击 `网易MC皮肤提取工具.exe`（或开发模式 `python main.py`）。启动后自动扫描网易版皮肤，扫描完成后列表展示所有候选。

## 第二步：找皮肤

- **开始扫描**：重新扫描网易版皮肤目录（自定义皮肤、皮肤包、商城/模组皮肤、开发皮肤等）
- **全盘搜索**：遍历所有盘符找皮肤贴图，较慢，可随时停止
- 列表中每项显示：缩略图、文件名、来源、体积；4D 皮肤包标注「4D包可能不适用Java版」

## 第三步：导出

点「我要下载」把皮肤保存到下载位置（默认桌面）。重名自动追加 `(1)`、`(2)` 序号，不会覆盖已有文件。

## 设置下载位置

点「⚙ 设置」→「选择文件夹…」选择保存目录，之后所有下载都进该目录。配置存在 `%APPDATA%\MC_Skin_Tool\config.json`。

## 常见问题

**扫不到皮肤？**
- 确认网易版《我的世界》已安装并下载过皮肤
- 确认游戏目录在 `F:\mc` 或已安装到默认位置（工具会同时扫 `%APPDATA%\MinecraftPC_Netease_PB`）
- 试试点「全盘搜索」

**导出的皮肤怎么给 Java 版用？**
- 单张 PNG：直接放进 Java 版启动器的皮肤设置（如 PCL2 / HMCL 的"本地皮肤"）
- 4D 包（zip）：需在 Java 版安装对应 4D 皮肤 mod 后导入

**工具联网吗？**
- 不联网。所有扫描、识别、导出都在本机完成，无任何网络请求。
